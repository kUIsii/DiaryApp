## DiaryApp v2.61.17-experimental

This experimental build refines the diary editor writing surface:

- Reworked the editor metadata area into a compact single-line strip.
- Moved mood, weather, tags, and location selection into an overlay panel so the page is not pushed down.
- Adjusted top spacing between date, title, and metadata for a calmer layout.
- Fixed the toolbar visibility icon to reflect the current toolbar state.
- Updated the writing mode button to show the current mode: focus or full editing.
- Replaced focus-mode font-size controls with a line-indent action.
- Improved ordered-list, checkbox, and checkmark alignment inside the WebView editor.
- Extended the ruled-paper feel across the editor page and reduced noisy/doubled line contrast.
- Reduced hidden bottom padding so the editor can use the available writing area more fully.
