🔐 一、登录页面 UI 升级

适配 7 主题家族

输入框聚焦色、按鈕渐变、装饰纹理都跟随当前主题（BLUE/GREEN/CYAN/ROSE/AMBER/CLAY/INK）

入场动画 + 微交互

标题→输入框→按钮 错开 slideUp 淡入（各间隔100ms）
按钮按压 spring 缩放、输入框聚焦光晕、注册/登录文字 crossfade

主题装饰底纹

各主题在背景叠加极淡的 Canvas 图案：水平线/圆点/波浪/椭圆/噪点/交叉线/网格点（<2%透明度）

👤 二、个人中心页面

个人中心框架

顶部圆形头像 + 昵称 + 手机号，下方卡片式功能列表

包含

  • 修改 PIN
  • 同步状态
  • 设备管理
  • 导出数据
  • 注销

同步状态指示器

首页圆点 + 设置页文字，显示 🟢已同步 / 🟡同步中 / 🔴未登录

多设备管理

显示已登录设备列表，可远程注销。Worker 新增 GET/DELETE /api/devices
