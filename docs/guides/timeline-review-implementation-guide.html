Step 3: "历史今天"通知 (0.5天)

使用 WorkManager 每日检查是否有历史日记，有则发送通知。

1 Worker 实现

class OnThisDayWorker( context: Context, params: WorkerParameters ) : CoroutineWorker(context, params) { override suspend fun doWork(): Result { val dao = (applicationContext as DiaryApplication) .database.diaryDao() val today = LocalDate.now() val entries = dao.getEntriesByMonthDay( today.monthValue, today.dayOfMonth ) val pastEntries = entries.filter { val year = Instant.ofEpochMilli(it.createdAt) .atZone(ZoneId.systemDefault()).year year < today.year } if (pastEntries.isNotEmpty()) { showOnThisDayNotification( pastEntries.size, pastEntries.maxOf { it.createdAt } ) } return Result.success() } }
OnThisDayWorker.kt (新增)

2 调度任务

// DiaryApplication.onCreate() 新增: val request = PeriodicWorkRequestBuilder( 1, TimeUnit.DAYS ) .setInitialDelay( calculateDelayToMorning(), TimeUnit.MILLISECONDS ) .build() WorkManager.getInstance(this).enqueueUniquePeriodicWork( "on_this_day", ExistingPeriodicWorkPolicy.KEEP, request )

Step 4: Memory Lane 纵向浏览 (1天)

1 VerticalPager 实现

@Composable fun MemoryLaneScreen( entries: List, onEntryClick: (Long) -> Unit, onDismiss: () -> Unit ) { val pagerState = rememberPagerState { entries.size } VerticalPager(state = pagerState) { page -> MemoryCard( entry = entries[page], yearDiff = currentYear - entryYear, onClick = { onEntryClick(entries[page].id) } ) } } @Composable fun MemoryCard( entry: DiaryEntry, yearDiff: Int, onClick: () -> Unit ) { GlassCard(modifier = Modifier.clickable(onClick = onClick)) { Text("${yearDiff}年前") Text(entry.title, style = headlineStyle) Text(entry.plainText.take(200)) // 心情/天气/标签 } }
