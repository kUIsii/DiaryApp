Step 1: WorkManager 自动备份 (0.5天)

使用 WorkManager 定期自动备份数据库。

1 Worker 实现

class AutoBackupWorker( context: Context, params: WorkerParameters ) : CoroutineWorker(context, params) { override suspend fun doWork(): Result { val db = (applicationContext as DiaryApplication) .database val backupManager = BackupManager(applicationContext) // 导出数据库 val backupFile = backupManager.exportDatabase(db) // 保留最近 7 个备份 cleanupOldBackups(keepCount = 7) return Result.success() } }

Step 2: 数据库加密 (2天)

使用 SQLCipher 加密数据库，保护用户隐私。

1 引入 SQLCipher

// build.gradle.kts 新增: implementation("net.zetetic:android-database-sqlcipher:4.5.4") implementation("androidx.sqlite:sqlite-ktx:2.4.0") // DiaryDatabase.kt 修改: val factory = SupportFactory( SQLiteDatabase.getBytes(password.toCharArray()) ) Room.databaseBuilder(context, DiaryDatabase::class.java, "diary.db") .openHelperFactory(factory) .build()
build.gradle.kts + DiaryDatabase.kt

2 密码管理

// 使用 Android Keystore 存储加密密钥: object DatabasePasswordManager { private const val KEY_ALIAS = "diary_db_key" fun getOrCreatePassword(context: Context): String { val prefs = context.getSharedPreferences( "secure_prefs", Context.MODE_PRIVATE ) return prefs.getString("db_password", null) ?: generatePassword().also { prefs.edit().putString("db_password", it).apply() } } private fun generatePassword(): String { val bytes = ByteArray(32) SecureRandom().nextBytes(bytes) return Base64.encodeToString(bytes, Base64.NO_WRAP) } }
DatabasePasswordManager.kt (新增)

注意：SQLCipher 迁移需要处理已有数据。首次启用时需要将明文数据库迁移到加密数据库。建议提供"启用加密"选项，让用户主动选择。

Step 3: Google Drive 云备份 (3天)

集成 Google Drive API，实现云端备份和恢复。

1 Google Drive API 集成

// build.gradle.kts 新增: implementation("com.google.android.gms:play-services-auth:20.7.0") implementation("com.google.apis:google-api-services-drive:v3-rev20231128-2.0.0") // BackupManager.kt 新增: suspend fun uploadToGoogleDrive( context: Context, backupFile: File ): Boolean { val credential = GoogleAccountCredential.usingOAuth2( context, listOf(DriveScopes.DRIVE_FILE) ) val drive = Drive.Builder( NetHttpTransport(), JacksonFactory(), credential ).build() val fileMetadata = com.google.api.services.drive.model.File().apply { name = "diary_backup_${System.currentTimeMillis()}.zip" parents = listOf("appDataFolder") } val content = FileContent("application/zip", backupFile) drive.files().create(fileMetadata, content).execute() return true }
