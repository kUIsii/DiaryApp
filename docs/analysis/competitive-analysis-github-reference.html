关键结论与建议

基于竞品调研，DiaryApp 的优势、差距和改进方向。

DiaryApp 的独特优势：心情追踪系统（10 种心情 + 1-6 级）在开源日记应用中最为完善。习惯追踪（HabitRecord）是独有的差异化功能。日历视图在同类应用中也较少见。

最大差距 - 架构：DiaryApp 是唯一的单模块架构。MyBrain、Superdiary、Journal 都采用多模块 Clean Architecture。单模块导致 DiaryDao 拥有 80+ 方法，HomeViewModel 拥有 15+ StateFlow，耦合度高。

最大差距 - 编辑器：Quill.js + WebView 方案在 Android 社区几乎无参考案例。compose-rich-editor (1,793 stars) 是 Compose 生态的主流选择。TipTap 在 Android 端也无成功案例。建议中期评估 compose-rich-editor 迁移可行性。
