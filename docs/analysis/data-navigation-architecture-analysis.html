Entity 设计

Room 数据库包含 8 个 Entity，覆盖日记、标签、待办、习惯、回收站、倒数日等核心功能。

article DiaryEntry

  • id: Long 主键自增
  • title: String 标题
  • content: String Quill Delta JSON
  • plainText: String 纯文本(搜索/预览)
  • moodLevel: Int? 心情 1-6
  • weather: String? 天气
  • location/lat/lng 位置信息
  • isFavorite: Boolean 收藏
  • createdAt/updatedAt 时间戳

sell Tag

  • id: Long 主键自增
  • name: String 标签名
  • color: Long 颜色值
  • isPreset: Boolean 预设标签

link DiaryTag

  • diaryId: Long FK → DiaryEntry
  • tagId: Long FK → Tag
  • 多对多关联表

check_box TodoItem

  • id: Long 主键自增
  • title/description 内容
  • isCompleted 完成状态
  • priority: Int 优先级 0-3
  • dueDate: Long? 截止日期
  • parentId: Long? 父任务(子任务)
  • category: String task/habit
  • recurringType 重复类型

loop HabitRecord

  • id: Long 主键自增
  • todoId: Long FK → TodoItem
  • recordDate: Long 打卡日期
  • note: String? 备注

delete TrashEntry

  • id: Long 主键自增
  • originalId: Long 原始ID
  • 保留 DiaryEntry 所有字段
  • deletedAt: Long 删除时间

image DiaryImage

  • id: Long 主键自增
  • entryId: Long FK → DiaryEntry
  • localPath: String 本地路径
  • sortOrder: Int 排序

timer CountDownItem

  • id: Long 主键自增
  • title: String 标题
  • targetDate: Long 目标日期
  • isPinned: Boolean 置顶

DAO 查询分析

DiaryDao 接口包含 80+ 个查询方法，是所有数据访问的单一入口。

search 查询模式

  • Flow 响应式 - 大部分查询返回 Flow>
  • Suspend 单次 - 导出/统计使用 suspend fun
  • LIKE 搜索 - plainText LIKE '%' || :query || '%'
  • strftime 日期 - 使用 SQLite strftime 提取月/日

warning 问题点

  • 单一接口 - 80+ 方法在一个 DAO 中，职责过重
  • 无分页 - getAllPreviews() 返回全量数据
  • 无 FTS - 搜索使用 LIKE，无全文索引
  • 无聚合 - 统计在 Kotlin 层计算，非 SQL
查询类别 方法数 返回类型 使用模块
日记 CRUD ~15 Flow/Suspend Home, Editor, Detail, Backup
搜索/过滤 ~8 Flow Home, Timeline, Favorites
标签管理 ~12 Flow/Suspend Home, Editor, Detail, Profile
待办/习惯 ~20 Flow/Suspend Todo
回收站 ~5 Flow/Suspend Trash
统计/导出 ~10 Suspend Stats, Backup
倒数日 ~5 Flow/Suspend CountDown

Migration 链

从 v1 到 v13 的完整迁移链，每次版本升级都保持数据兼容。

版本 变更内容 影响 Entity
v1→v2 占位迁移，无实际变更 -
v2→v3 添加 isFavorite 字段 DiaryEntry
v3→v4 创建 todo_items 表 TodoItem
v4→v5 添加索引 (createdAt, isFavorite, moodLevel, dueDate, isCompleted) DiaryEntry, DiaryTag, TodoItem
v5→v6 添加 category 字段 (task/habit) TodoItem
v6→v7 添加 reminderTime 字段 TodoItem
v7→v8+ 添加 tags, images, trash, countdown, habit_records 等 多个 Entity
v13 当前版本 - 8 个 Entity，完整索引 所有

导航架构

使用 Navigation Compose 实现的底部导航 + 路由系统。

底部导航栏 (4 Tab)

home 首页 Home 日记列表 + 日历视图
calendar_month 时间线 Timeline 按月分组的日记时间线
check_box 待办 Todo 待办事项 + 习惯打卡
person 我的 Profile 个人中心 + 设置

二级路由

edit_note editor?diaryId=&draftId= 编辑器 (支持新建/编辑/草稿)
visibility detail/{id} 日记详情页
bar_chart stats 统计页面
favorite favorites 收藏列表
delete trash 回收站
cloud_upload backup 备份管理
settings settings 应用设置
science experimental_features 实验功能中心

info 导航问题

  • URL 参数解析 - Editor 路由使用 URL 参数，解析逻辑分散
  • 返回栈管理 - 多级返回时行为不一致
  • Deep Link - 不支持外部 Deep Link
  • 动画 - 页面切换动画不统一

check_circle 优化建议

  • Type-safe Navigation - 使用 Kotlin Serialization 路由
  • 统一动画 - 所有页面使用相同的 enter/exit 动画
  • Deep Link - 支持 diary://entry/{id} 外部链接
  • 导航状态保存 - 配置变更时保存导航状态
