统计模块 StatsScreen

StatsScreen 是应用的数据分析中心，展示日记统计数据、心情趋势、标签分布等。

check_circle 已实现功能

  • 总览统计 - 总日记数、连续天数、本月日记数
  • 心情分布 - 心情等级柱状图/饼图
  • 标签使用 - 标签使用频率排行
  • 写作时间 - 一天中的写作时间分布
  • 日历热力图 - GitHub 风格的年度热力图
  • 心情趋势 - 30天心情变化折线图

info 技术实现

  • 数据源 - getAllPreviews() 全量加载后 Kotlin 计算
  • 图表 - 自定义 Canvas 绘制，非第三方库
  • 动画 - AnimatedCounter 数字动画
  • 性能 - 全量数据在内存中聚合，大数据集可能卡顿

优化机会：统计模块可以使用 SQL 聚合查询替代 Kotlin 内存计算。例如 SELECT moodLevel, COUNT(*) FROM diary_entries GROUP BY moodLevel 可以直接在数据库层完成心情分布统计。

实验功能中心

新创建的实验功能管理模块，允许用户启用/禁用未稳定的功能。

science ExperimentalFeaturesScreen

  • 功能列表 - 展示所有可用的实验功能
  • 开关控制 - 每个功能独立启用/禁用
  • 持久化 - ExperimentalFeaturesPreferences 存储状态
  • 导航集成 - 从首页 FunctionMenu 进入

extension ExperimentalFeatureLogic

  • 功能注册 - 集中管理所有实验功能的元数据
  • 状态查询 - isFeatureEnabled() 判断功能是否启用
  • 路由控制 - 根据功能状态动态显示/隐藏导航项

新增 已注册的实验功能

  • 首页滑动目标 - resolveMainScreenSwipeTarget() 控制首页左右滑动行为
  • 更多功能待注册...

详情页 DiaryDetailScreen

日记详情展示模块，使用 WebView 渲染 Delta JSON 内容。

check_circle 已实现功能

  • WebView 渲染 - viewer.html 渲染 Delta JSON
  • 元数据展示 - 心情/天气/位置/标签/时间
  • 收藏操作 - 切换收藏状态
  • 编辑入口 - 跳转到 EditorScreen
  • 删除操作 - 软删除到回收站
  • "历史今天" - 显示同月同日的历史日记

info 已知问题

  • 嵌套滚动 - WebView 在 verticalScroll Column 中滚动冲突
  • 2MB 限制 - 内容超过 2MB 时回退到纯文本
  • Base64 开销 - 每次加载都进行 Base64 编解码
  • 暗色闪烁 - 深色模式切换时有可见闪烁

优化建议

按优先级排序的改进方案。

P0 SQL 聚合查询

统计模块改用 SQL 聚合查询，避免全量数据加载到内存。新增 getMoodDistribution()、getTagUsageStats() 等 DAO 方法。

预计工作量: 1天 | 影响: StatsViewModel + DiaryDao

P0 详情页滚动修复

将 header/footer 注入 WebView 内部，移除外层 verticalScroll，让 WebView 独占滚动。或使用 NestedScrollConnection 转发 fling。

预计工作量: 2天 | 影响: DiaryDetailScreen

P1 扩展实验功能

将更多功能注册为实验功能：首页 HorizontalPager 日历、新版编辑器、AI 写作助手等。让用户选择是否启用。

预计工作量: 0.5天 | 影响: ExperimentalFeatures

P1 图片画廊

详情页添加图片点击放大、全屏浏览、左右滑动切换功能。通过 JS Bridge 接收图片点击事件。

预计工作量: 2天 | 影响: DiaryDetailScreen

P2 阅读模式

详情页添加阅读模式：沉浸式全屏、字体大小调节、背景色选择。使用 URL 参数传递主题避免闪烁。

预计工作量: 1天 | 影响: DiaryDetailScreen

P2 分享增强

详情页添加分享按钮，支持文字分享、图片分享、Markdown 导出。使用系统 ShareSheet。

预计工作量: 1天 | 影响: DiaryDetailScreen + DiaryExporter
