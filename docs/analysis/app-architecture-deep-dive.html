架构分层

单模块 MVVM 架构，无 Repository 层。ViewModel 直接持有 DAO 引用。

架构特点：无 Repository 抽象层。ViewModel 直接调用 DAO 方法。这意味着业务逻辑（如标签映射、日期计算）散落在各个 ViewModel 中，导致 HomeViewModel 拥有 15+ StateFlow，TimelineViewModel 重复实现 tagsMap 等逻辑。

数据模型 (8 Entity)

Room Database v13，包含 8 个 Entity 和 13 个迁移版本。

Entity 核心字段 索引 关联
DiaryEntry title, content (Delta JSON), plainText, moodLevel (1-6), weather, location/lat/lng, isFavorite createdAt, isFavorite, moodLevel 1:N Tag, 1:N Image
Tag name, color, icon, usageCount - N:M DiaryEntry
DiaryTag diaryId, tagId (交叉表) diaryId, tagId DiaryEntry ↔ Tag
TodoItem title, description, priority, dueDate, isCompleted, isPinned, parentId, category, tags, reminderTime, habitFrequency dueDate, isCompleted, category, reminderTime, parentId, tags 自引用 (parentId)
HabitRecord todoId, recordDate, note, diaryEntryId (todoId+recordDate) UNIQUE, recordDate, diaryEntryId FK TodoItem, FK DiaryEntry
TrashEntry originalId, title, content, deletedAt, expiresAt - 软删除容器
DiaryImage diaryEntryId, imagePath, thumbnailPath, caption, sortOrder diaryEntryId FK DiaryEntry
CountDownItem title, targetDate, color, icon, isPinned targetDate 独立
