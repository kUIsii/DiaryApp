问题诊断

当前代码中存在的性能和架构问题。

warning 性能问题

  • 全量加载 - getAllPreviews() 加载所有日记到内存，1000+ 条时内存压力大
  • Kotlin 过滤 - 日期/标签/心情过滤在 Kotlin 层完成，非 SQL 层
  • 重复计算 - dayInfoMap
  • 无分页 - LazyColumn 加载全部数据，无懒加载

info 架构问题

  • ViewModel 膨胀 - HomeViewModel 包含 15+ 个 StateFlow
  • 搜索缺失 - 搜索功能仅在 TimelineScreen 存在
  • 无"历史今天" - onThisDayEntries 存在但未在首页展示
  • 无周报摘要 - weeklySummary 数据已计算但未渲染

关键发现：HomeViewModel 已经计算了 weeklySummary、moodTrend、onThisDayEntries 等数据，但 HomeScreen 并未使用这些数据。这是一个低成本高收益的优化机会。

优化建议

按优先级排序的改进方案。

P0 引入 Paging3

将 getAllPreviews() 替换为 PagingSource，实现分页加载。首屏只加载 30 条，滚动时懒加载更多。

预计工作量: 2天 | 影响: HomeViewModel + HomeScreen

P0 添加首页搜索

在日历下方添加搜索栏，支持全文搜索 + 心情/天气/标签过滤。复用 TimelineScreen 的搜索逻辑。

预计工作量: 1天 | 影响: HomeScreen + HomeViewModel

P1 展示已有数据

将已计算但未使用的 weeklySummary、moodTrend、onThisDayEntries 渲染到首页。低成本高收益。

预计工作量: 1天 | 影响: HomeScreen

P1 HorizontalPager 日历

用 HorizontalPager 替换箭头导航，支持左右滑动切换月份/周。提升日历交互体验。

预计工作量: 1天 | 影响: CalendarView

P2 左滑操作

EntryCard 支持左滑显示收藏/删除按钮。使用 SwipeToDismiss 或自定义手势。

预计工作量: 1天 | 影响: EntryCard

P2 情绪热力图

在月视图日期下方添加微型热力图条，显示当月心情分布。使用 Canvas 绘制。

预计工作量: 0.5天 | 影响: CalendarView
