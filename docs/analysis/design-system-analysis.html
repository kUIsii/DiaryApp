主题模式

DiaryApp 支持 4 种主题模式，通过 ThemeMode 枚举管理。

light_mode Fog Blue Light

雾蓝灰浅色模式。冷色调蓝灰背景，温暖的棕色/琥珀色点缀。

  • 背景 - #F5F7FA → #EFF3F8 → #E8EDF4
  • 文字 - #2C3344 (主) / #5A6577 (次)
  • 强调 - #6B8DB5 (蓝) / #B5926B (棕)

dark_mode Fog Blue Dark

雾蓝灰深色模式。深邃的蓝黑背景，柔和的蓝光强调。

  • 背景 - #0B0D12 → #0E1018 → #11131C
  • 文字 - #D8E0F0 (主) / #9AA8C0 (次)
  • 强调 - #88B0D4 (蓝) / #D4A878 (棕)

eco Moss Green Light

苔藓绿浅色模式。温暖的纸白背景，自然的绿色点缀。

  • 背景 - #F6F7F4 → #EFF2EB → #E5EAE0
  • 文字 - #2E3328 (主) / #5A6450 (次)
  • 强调 - #7BA06E (绿) / #C4A06B (棕)

dark_mode Moss Green Dark

苔藓绿深色模式。深绿黑背景，柔和的绿光点缀。

  • 背景 - #0B0D0A → #0E110D → #111410
  • 文字 - #D8E4D0 (主) / #9AAA90 (次)
  • 强调 - #8BC07A (绿) / #D4B078 (棕)

组件库

可复用的 UI 组件，提供一致的视觉和交互体验。

crop_square GlassCard

毛玻璃效果卡片，支持 4 种主题模式的自适应背景/边框。可选阴影、渐变、自定义圆角。

  • 使用率 - 几乎所有页面都使用
  • 特性 - 主题感知、backdrop-filter 模糊

gradient GradientBackground

页面级渐变背景，自动适配当前主题模式。作为所有页面的根容器。

  • 使用率 - 所有主页面
  • 特性 - 三层渐变 + 网格纹理

touch_app PressableScale

按压缩放效果组件，提供触觉反馈。用于可点击元素。

  • 使用率 - 按钮、卡片点击
  • 特性 - 弹簧动画、触觉反馈

tag TagChip

标签芯片组件，显示标签名称和颜色。支持选中状态。

  • 使用率 - 日记列表、详情页、编辑器
  • 特性 - 自定义颜色、圆角胶囊

counter_0 AnimatedCounter

数字动画组件，支持数字滚动效果。用于统计页面。

  • 使用率 - StatsScreen
  • 特性 - 弹簧动画、格式化

menu FunctionMenu

功能下拉菜单组件，显示带图标的菜单项列表。

  • 使用率 - HomeScreen 右上角
  • 特性 - 动画展开、点击外部关闭
