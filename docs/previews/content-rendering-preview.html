方案评估
+
UI 一致性: 与 Compose 架构完全统一, 样式/主题/动画一体化管理
+
精确控制: 每个富文本元素都是独立 Composable, 可精确控制交互和样式
-
开发成本高: 需自行实现 Markdown 解析器 + AnnotatedString 构建, 工作量大
-
TextField 局限: Compose TextField 对复杂富文本编辑支持尚不完善
!
不支持回退: 若当前页面是 View 体系, 混用 Compose 增加复杂度

维度 Delta+WebView Markdown+Markwon Compose原生

IME兼容 问题多 完美 良好
迁移成本 无需迁移 中等 高
可扩展性 受限WebView 插件丰富 完全可控
生态成熟度 Quill维护中 社区活跃 快速迭代中
迁移路径 (Markdown方案)
1
编写转换器: Delta JSON --> Markdown, 处理内联样式和嵌入内容映射
2
集成 Markwon: 添加依赖, 配置 GFM 扩展、图片加载、代码高亮
3
实现编辑器: 基于 EditText + Markdown 语法快捷键, 支持实时预览
4
批量迁移: 后台任务转换存量日记, 保留原文件做回退备份
5
灰度发布: 先对新日记使用新渲染, 稳定后全量切换
