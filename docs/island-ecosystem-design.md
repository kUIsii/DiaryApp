# 小岛深度生态系统设计文档

## 设计目标

让小岛从"静态装饰画"变成"活的生态世界"，用户每次打开都有新发现，产生持续探索的欲望。

---

## 一、小岛生态系统

### 1.1 动物行为系统

#### 行为模式定义

| 动物 | 白天行为 | 夜间行为 | 特殊条件 |
|------|----------|----------|----------|
| 小鸟 | 在树间跳跃、飞翔 | 栖息在灯塔/屋顶 | 茂盛度>0.7时出现鸟群 |
| 蝴蝶 | 在花丛中飞舞 | 休息（停在叶子上） | 花海装饰存在时出现 |
| 松鼠 | 在树上攀爬、捡松果 | 在树洞中休息 | 大树装饰存在时出现 |
| 猫头鹰 | 躲在树荫中睡觉 | 睁眼巡视、偶尔飞过 | 夜间20:00-4:00活跃 |
| 猫咪 | 追蝴蝶、晒太阳 | 在小木屋窗台蜷缩 | 猫咪+蝴蝶同时存在时触发追蝶动画 |
| 青蛙 | 躲在草丛 | 在池塘边鸣叫 | 雨天+喷泉同时存在时出现 |
| 萤火虫群 | 不可见 | 夜间发光飞舞 | 茂盛度>0.7+夜间 |

#### 动物互动规则

```
触发条件                        互动表现
---------------------------------------------------------
猫咪 + 蝴蝶同在               猫咪扑向蝴蝶，蝴蝶飞走
小鸟 + 灯塔同在               小鸟停在灯塔顶部休息
松鼠 + 大树同在               松鼠在树干上攀爬
猫头鹰 + 小木屋同在           猫头鹰停在屋顶夜间巡视
所有动物 + 降雨               动物们寻找遮蔽处躲避
所有动物 + 大风               动物们低头抵抗风力
```

### 1.2 植物季节变化

#### 季节判定

基于真实月份自动判定：
- 春季(3-5月)：花朵绽放、嫩绿新芽
- 夏季(6-8月)：茂盛浓绿、向日葵盛开
- 秋季(9-11月)：金黄落叶、果实成熟
- 冬季(12-2月)：萧瑟枯枝、偶尔飘雪

#### 植被状态表

| 季节 | 大树状态 | 花海状态 | 草地状态 | 特效 |
|------|----------|----------|----------|------|
| 春 | 嫩绿新芽 | 樱花/桃花绽放 | 嫩绿生长 | 飘落花瓣 |
| 夏 | 浓绿茂盛 | 向日葵/薰衣草 | 深绿茂密 | 阳光光斑增强 |
| 秋 | 金黄/红色 | 菊花/桂花 | 枯黄渐变 | 飘落红叶 |
| 冬 | 枯枝（无叶） | 梅花（稀少） | 枯黄稀疏 | 偶尔飘雪 |

### 1.3 生态链系统

```
植被茂盛度 > 0.6
    ↓
昆虫出现（蝴蝶、萤火虫）
    ↓
鸟类出现（小鸟、猫头鹰）
    ↓
小型哺乳动物出现（松鼠、猫咪）
    ↓
生态完整度提升 → 解锁稀有装饰
```

**生态完整度计算**：
- 基础分：茂盛度 × 30
- 动物多样性：每种动物 +10分
- 装饰协同：存在组合效果 +20分
- 满分100分，不同分数解锁不同生态称号

### 2.2 季节性特殊场景

#### 春季
- **樱花飘落**：3-4月，花海装饰周围飘落粉色花瓣
- **清明雨**：4月初，雨滴带有淡淡的青绿色

#### 夏季
- **萤火虫海**：7月夜晚，大量萤火虫在草丛中飞舞
- **雷阵雨**：午后突然降雨，伴随闪电

#### 秋季
- **红叶雨**：10月，树叶从橙色渐变为红色后飘落
- **丰收果实**：大树上出现小小的果实装饰

#### 冬季
- **初雪**：12月首次降温，飘落细小雪花
- **圣诞彩灯**：12月24-25日，小木屋出现彩灯装饰
- **春节灯笼**：春节前后，建筑上挂起红灯笼

## 三、小岛故事与氛围

### 3.1 小岛的"情绪"

小岛不只是反映用户心情，它有自己的"情绪状态"：

| 小岛情绪 | 触发条件 | 视觉表现 |
|----------|----------|----------|
| 活力满满 | 连续7天积极心情 | 天空更蓝、动物更活跃、花朵绽放 |
| 宁静祥和 | 连续3天平静心情 | 水面如镜、微风轻拂、萤火虫出现 |
| 忧郁低沉 | 连续3天低落心情 | 天空阴沉、动物躲藏、落叶增多 |
| 元气恢复 | 从低落转为积极 | 阳光穿透云层、彩虹出现 |
| 神秘莫测 | 夜间+高宁静度 | 星星格外明亮、有神秘光点 |

#### 小岛情绪计算

```kotlin
data class IslandMood(
    val mood: String,           // "energetic" | "calm" | "melancholy" | "recovery" | "mysterious"
    val intensity: Float,       // 0.0-1.0 情绪强度
    val since: Long,            // 情绪开始时间
    val triggeredBy: String     // 触发原因描述
)
```

### 3.2 记忆碎片系统

小岛会"记住"重要的时刻，并在特定条件下重现：

#### 记忆碎片类型

| 纪念日类型 | 触发条件 | 纪念日表现 |
|------------|----------|------------|
| 首次记录日 | 每年同一天 | 小岛出现一年前的装饰布局 |
| 连续记录里程碑 | 7/30/100/365天 | 出现对应的纪念装饰 |
| 心情转折点 | 从连续低落转为积极 | 出现"破晓之光"特效 |
| 重要对话 | 日记中提到特定人物 | 出现该人物相关的温馨场景 |

#### 记忆碎片数据

```kotlin
data class MemoryFragment(
    val id: Long,
    val type: String,           // "anniversary" | "milestone" | "turning_point"
    val originalTime: Long,     // 原始事件时间
    val triggerCondition: String, // 重现条件
    val fragmentDescription: String, // 记忆内容描述
    val visualEffect: String    // 视觉效果ID
)
```

### 3.3 小岛叙事

小岛有自己的"故事线"，随用户使用逐步展开：

**第一章：苏醒**（0-10级）
- 小岛从沉睡中苏醒
- 逐渐出现基础装饰
- "小岛感受到了你的陪伴..."

**第二章：生长**（11-30级）
- 生态系统逐渐完善
- 动物们开始出现
- "小岛变得生机勃勃..."

**第三章：守护**（31-50级）
- 守护者雕像出现
- 小岛开始"回报"用户
- "小岛记住了你的每一次记录..."

**第四章：永恒**（51级+）
- 记忆树永久存在
- 所有秘密解锁
- "你和小岛的故事，将永远延续..."

## 四、探索机制

### 4.1 元素交互系统

#### 可点击元素

| 元素 | 点击效果 | 解锁条件 |
|------|----------|----------|
| 天空 | 显示当前时间、天气、小岛情绪 | 默认可点 |
| 海洋 | 显示海洋深度、波浪状态 | 默认可点 |
| 建筑 | 显示建筑名称、建造故事 | 建筑存在时可点 |
| 动物 | 显示动物名字、当前状态 | 动物存在时可点 |
| 植物 | 显示植物种类、季节状态 | 植物存在时可点 |

#### 交互反馈

点击元素后，底部弹出信息卡片：

```
┌─────────────────────────────────────┐
│  小鸟 "啾啾"                        │
│                                     │
│  状态: 在灯塔上休息                  │
│  心情: 满足                          │
│                                     │
│  "这只小鸟是3天前飞来小岛的，        │
│   它最喜欢停在灯塔上看日落。"         │
│                                     │
│  [关闭]                             │
└─────────────────────────────────────┘
```

### 4.2 条件解锁系统

#### 解锁类型

| 解锁类型 | 说明 | 示例 |
|----------|------|------|
| 等级解锁 | 达到特定等级 | 等级5解锁小木屋 |
| 行为解锁 | 完成特定行为 | 连续7天记录解锁灯塔 |
| 探索解锁 | 发现隐藏元素 | 发现3个秘密解锁特殊装饰 |
| 时间解锁 | 在特定时间登录 | 冬季登录解锁雪景装饰 |
| 组合解锁 | 同时拥有特定装饰 | 小木屋+花海=温馨家园 |

#### 解锁动画

每次解锁都设计"惊喜感"：

1. **光芒汇聚**：装饰位置出现光点汇聚
2. **逐渐显现**：装饰从虚影变为实体
3. **庆祝特效**：星星/花瓣/光芒四散
4. **解锁文案**：展示装饰的故事和意义

```
解锁文案示例:

灯塔解锁:
"灯塔守护着这片海域，
为迷途的船只指引方向。
它的光，也照亮了小岛的夜晚。"

猫咪解锁:
"一只小猫悄悄来到了小岛，
它喜欢追蝴蝶，也喜欢晒太阳。
有了它，小岛变得更加温馨。"
```

## 六、数据模型扩展

### 6.1 新增数据表

```kotlin
// 小岛情绪状态
@Entity(tableName = "island_mood")
data class IslandMoodState(
    @PrimaryKey val id: Long = 1,
```

## 八、文案设计

### 8.1 发现惊喜文案

```
发现稀有元素:
"你发现了小岛的秘密！这是属于你的特别时刻。"

发现季节场景:
"季节更替，小岛换上了新装。你注意到了吗？"

发现彩蛋:
"恭喜！你发现了隐藏的彩蛋。继续探索，更多惊喜等着你。"

发现组合效果:
"当这些装饰在一起时，产生了意想不到的化学反应！"
```

### 8.2 解锁提示文案

```
等级解锁:
"小岛成长了！新的装饰已经准备就绪。"

行为解锁:
"你的坚持让小岛焕然一新。这是你应得的奖励。"

探索解锁:
"你的好奇心让小岛展现了更多面貌。"

时间解锁:
"这个季节专属的装饰，现在属于你了。"
```

### 8.3 小岛叙事文案

```
第一章 - 苏醒:
"小岛从沉睡中苏醒，感受到了你的陪伴。
它开始慢慢苏醒，准备迎接新的故事。"

第二章 - 生长:
"小岛变得生机勃勃，动物们开始在这里安家。
每一天，它都在悄悄成长。"

第三章 - 守护:
"小岛记住了你的每一次记录，每一次心情。
它准备好了，要守护你的回忆。"

第四章 - 永恒:
"你和小岛的故事，已经成为了传说。
这片天地，将永远铭记你的足迹。"
```

### 8.4 元素交互文案

```
点击天空:
"今天是[晴天/雨天]，小岛的心情是[平静/活力]。"

点击海洋:
"海面[波光粼粼/风平浪静]，深度约[X]米。"

点击动物:
"[动物名]正在[位置]，看起来[心情]。"

点击建筑:
"这是[建筑名]，它在[X]级时来到小岛。"
```
