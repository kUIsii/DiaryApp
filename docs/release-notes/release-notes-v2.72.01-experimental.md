# v2.72.01 更新日志

## 场景环境音深度优化

### 真实音频文件
- 植入 5 个 CC0 真实环境音（白噪音、雨声、海浪、森林、咖啡厅）
- 替代之前算法生成的劣质音效

### 后台播放
- 退出页面后音频继续在后台播放
- 通知栏显示当前播放内容，支持暂停/继续/停止
- 集成 MediaSession，锁屏可控制播放

### 独立音量与混音
- 每个音效有独立的音量滑块，可自由调节混音比例
- 可同时播放多个音效混合

### 淡入淡出
- 播放/停止时 200ms 平滑过渡，避免爆音

### 音频焦点
- 其他 App 播放音乐时自动降低音量（duck）
- 来电或导航播报时暂停，结束后恢复

### 定时关闭
- 支持 15/30/60/90 分钟倒计时
- 最后 2 分钟音量逐渐降低到静音，不会突然断掉

### 音效预设
- 内置 3 个快速预设（雨天学习、森林冥想、咖啡厅工作）
- 可保存当前音效组合为用户预设

## 其他清理
- 移除岛屿/宠物功能相关代码和文档
