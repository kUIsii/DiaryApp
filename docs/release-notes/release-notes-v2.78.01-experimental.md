# v2.78.01-experimental

本次更新把工具区的第一个大类继续推进为“数据分析中心”，重点不只是改名，而是把统计页真正做成可用的分析入口。

## 数据分析中心

- 重新组织为“总览、洞察、深挖”三层结构
- 首页补上关键指标、核心洞察和深挖入口，减少空壳感
- 统一承接月度、季度、年度时间报告入口
- 把心情趋势、写作习惯、天气与心情等内容整合为更清晰的分析链路
- 共享分析逻辑下沉到独立文件，减少页面之间的重复计算

## 工具页

- 工具区中的统计入口语义统一为“数据分析中心”
- 与分析相关的入口说明更聚焦，减少用户理解成本

## 稳定性

- 提高 Gradle 和 Kotlin 的内存配置，降低本地编译时的内存压力
- 新增分析中心共享逻辑测试，保证总结与入口分组规则稳定
