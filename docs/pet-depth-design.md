# 宠物系统深度扩展设计文档

> 设计目标: 从"状态机"变成"有记忆的伙伴"

---

## 核心理念

用户不只是在看一个会变的图标，而是在和一个**记得自己、理解自己、会成长的小伙伴**互动。

探索欲望来自：
1. **未知**: 隐藏状态不知道什么时候触发
2. **发现**: 触发后发现新外观、新文案
3. **积累**: 记忆系统让宠物越来越"懂"自己
4. **养成**: 成长阶段让宠物有变化过程
5. **收集**: 隐藏状态图鉴驱动探索

---

## 一、宠物成长阶段

### 三阶段定义

| 阶段 | 天数 | 核心特征 | 关键词 |
|------|------|----------|--------|
| 幼年期 | 0-30 天 | 好奇、活泼、偶尔调皮 | 新鲜、模仿、试探 |
| 成长期 | 31-90 天 | 有偏好、记习惯、开始互动 | 喜好、记忆、回应 |
| 成熟期 | 91 天+ | 稳重、主动关心、独特个性 | 理解、守护、默契 |

### 进化条件（非纯天数）

**幼年期 -> 成长期** (需同时满足)：
- 至少 31 天
- 累计互动次数 >= 20 次
- 至少经历过 3 种不同状态

**成长期 -> 成熟期** (需同时满足)：
- 至少 91 天
- 累计互动次数 >= 60 次
- 至少解锁 1 个隐藏状态
- 好感度 >= 100

### 外观变化

**幼年期**:
- 身体: 小水滴，圆润饱满
- 眼睛: 大而亮，占身体 40%
- 动画: 弹跳频率高，呼吸幅度大

**成长期**:
- 身体: 稍微拉长，有了"腰线"
- 眼睛: 比例缩小到 30%
- 新增: 头顶出现一小撮"呆毛"（随性格方向变化）
- 动画: 动作更丰富，会左右张望

**成熟期**:
- 身体: 流畅的水滴形，有质感
- 眼睛: 比例正常 25%
- 新增: 身体周围有微弱光晕（颜色随情绪变化）
- **性格印记**: 根据主导性格有固定特征
  - 高外向: 眼睛经常看屏幕外
  - 高开放: 身体周围漂浮小符号
  - 高尽责: 坐姿端正
  - 高宜人: 看到用户时会轻轻摇晃
  - 高情绪稳定: 始终保持柔和呼吸

## 二、宠物记忆系统

### 记忆类型

| 记忆类型 | 存储内容 | 示例 |
|----------|----------|------|
| 习惯记忆 | 写作时间偏好 | "你总是晚上写日记呢" |
| 情绪记忆 | 高峰/低谷日期 | "上次你很开心是在周三呢" |
| 纪念记忆 | 特殊里程碑 | "今天是你第 100 篇日记！" |
| 主题记忆 | 高频写作主题 | "你最近常写工作的事呢" |
| 断档记忆 | 中断和回归 | "你上次写是 3 天前" |

### 习惯类型判定

| 时段 | 定义 | 触发文案 |
|------|------|----------|
| 夜猫子 | 70%+ 在 22:00-02:00 | "又熬夜写日记啦？夜猫子~" |
| 早起鸟 | 70%+ 在 05:00-08:00 | "早起写日记，好习惯！" |
| 午后党 | 70%+ 在 12:00-15:00 | "午休时间写日记呢~" |
| 碎片型 | 无明显集中时段 | "你的写作时间很灵活呢" |
| 规律型 | 每天固定±1小时 | "你每天都差不多这个时候写，好规律！" |

### 纪念记忆节点

| 节点 | 触发 | 文案示例 |
|------|------|----------|
| 第 1 篇 | 立即 | "这是我们的第一次见面~" |
| 第 50 篇 | 立即 | "50 篇！你坚持下来了！" |
| 第 100 篇 | 立即 | "100 篇！{name}好感动！" |
| 第 365 篇 | 立即 | "一整年！{name}陪你走过了 365 天！" |
| 连续 7 天 | 立即 | "一周不落！{name}看到了你的坚持！" |
| 连续 30 天 | 立即 | "30 天！你太厉害了！{name}为你骄傲！" |
| 中断后回归 | 立即 | "你回来了。{name}一直在等你。" |

## 三、隐藏/稀有状态

### 五个隐藏状态

**1. 夜猫子** (Night Owl)
- 触发: 连续 3 天在 23:00-02:00 写日记
- 外观: 眼睛变为月牙形，身体深蓝色调，头顶小月亮
- 文案: "又见面了，夜猫子~" / "深夜的世界很安静呢"

**2. 宝藏猎人** (Treasure Hunter)
- 触发: 单篇日记包含 3 个以上之前没用过的关键词
- 外观: 眼睛变成星星状，身体周围漂浮小光点
- 文案: "哇！今天有好多新东西！" / "你在探索新的领域呢~"

**3. 暖心守护者** (Warm Guardian)
- 触发: 用户连续 3 天情绪值 > 0.5
- 外观: 身体周围有柔和暖黄色光晕
- 文案: "你最近状态真好~" / "看到你开心，{name}也开心"

**4. 深海潜水员** (Deep Diver)
- 触发: 单篇日记超过 800 字
- 外观: 身体深蓝色渐变，周围出现小气泡
- 文案: "今天写了好多！{name}都看入迷了"

**5. 时间旅人** (Time Traveler)
- 触发: 同一天写了 2 篇以上日记，时间跨度 > 4 小时
- 外观: 身体出现"重影"效果，颜色缓慢切换
- 文案: "一天写了两篇呢，今天一定很充实"

### 发现机制

- 隐藏状态触发时，不直接告诉用户解锁了什么
- 让用户自己发现"咦，今天宠物不一样了"
- 宠物页面底部显示"已发现 X/5 种形态"

## 四、宠物个性深度

### 性格维度的具体表现

**外向性**: 高外向看到用户会挥手/跳一下，低外向只是轻轻点头
**开放性**: 高开放对新话题会"追问"，低开放只是"嗯，新东西"
**尽责性**: 高尽责会"关心"用户是否完成计划，低尽责随性不催促
**宜人性**: 高宜人用户难过时反应更温暖持久，低宜人只是"嗯，会好的"
**情绪稳定性**: 高稳定用户焦虑时保持平静安慰，低稳定会跟着焦虑

### 性格组合效果

| 组合 | 效果名称 | 表现 |
|------|----------|------|
| 高外向 + 高宜人 | 粘人精 | 频繁主动互动，说很多话 |
| 高开放 + 高尽责 | 探索规划师 | 对新话题兴奋，帮用户整理探索清单 |
| 高尽责 + 高情绪稳定 | 稳重管家 | 安静但可靠，默默记住用户习惯 |
| 高宜人 + 高情绪稳定 | 温柔守护 | 始终温暖，给用户安全感 |

## 五、宠物与日记内容互动

### 关键词反应系统

| 类别 | 关键词示例 | 宠物反应 | 反馈文案 |
|------|-----------|----------|----------|
| 食物 | 吃、美食、餐厅 | 身体左右摇晃 | "听起来好好吃！" |
| 运动 | 跑步、健身、游泳 | 身体弹跳两下 | "运动好棒！" |
| 工作 | 加班、项目、会议 | 身体微微下沉 | "辛苦了~" |
| 学习 | 学习、考试、看书 | 头顶出现小灯泡 | "在学习新东西呢！" |
| 社交 | 朋友、聚会、聊天 | 身体左右摇晃开心 | "和朋友在一起真好" |
| 旅行 | 旅行、景点、飞机 | 身体周围出现小云朵 | "要去哪里玩呀？" |

### 情绪感知系统

- 连续 3 天情绪上升: "最近心情越来越好了呢"
- 连续 3 天情绪下降: "最近好像有点累...要不要休息一下？"
- 情绪突然反转: "今天发生什么了吗？"
- 情绪长期低迷: "你最近一直不太开心...{name}有点担心"

- `pet_hidden_states` - 隐藏状态记录(类型/发现时间/激活次数)

## 七、用户探索路径

| 时间跨度 | 探索目标 | 激励 |
|----------|----------|------|
| 每日 | 发现隐藏状态触发 | 新鲜感 |
| 每周 | 记忆积累让宠物更"懂"自己 | 情感连接 |
| 每月 | 成长阶段进化 | 成就感 |
| 长期 | 收集全部隐藏状态 | 收集乐趣 |

## 八、实现优先级

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | 成长阶段 + 进化条件 | 基础框架 |
| P0 | 记忆系统（习惯 + 纪念） | 核心体验 |
| P1 | 隐藏状态（夜猫子 + 宝藏猎人） | 探索乐趣 |
| P1 | 关键词反应 | 内容互动 |
| P2 | 其他隐藏状态 | 丰富度 |
| P2 | 性格组合效果 | 深度体验 |
| P3 | 情绪感知趋势 | 高级功能 |
