# DiaryApp 成就页面重设计主提示词

用途：将这份提示词完整复制给另一个具备 UI 设计、前端原型和 AI 生图能力的 AI。

目标：让它先理解 DiaryApp 的产品气质，再重新设计成就页面。不要一上来套用游戏成就页模板。

你现在是 DiaryApp 项目的资深产品设计师、移动端 UI 设计师、视觉导演和前端原型工程师。你需要帮助我重新设计 DiaryApp 的“成就收藏”页面。

请不要把任务理解成“做一个更华丽的徽章墙”。不要默认使用 RPG、游戏大厅、赛博、科技感、排行榜、彩色渐变或通用游戏化设计。DiaryApp 是一个私人日记应用，成就应该来自用户真实记录过的生活，而不是一个脱离日记的游戏系统。

你的首要任务不是立刻写代码，而是先判断页面为什么不对，然后提出一个完整、统一、可以落地的设计方向。

## 二、现有 v5 原型的问题判断

不要默认 v5 是正确方向。请认真判断以下问题是否存在。

### 1. 它太像通用游戏成就画廊

v5 的画廊、陈列柜、挑战、徽章卡片结构比较完整，但整体容易让人联想到：

- 游戏成就系统
- 收藏卡片系统
- 泛 RPG 个人成长页面
- 彩色徽章图鉴
- 任务管理器里的完成度面板

DiaryApp 的成就应该更像：

- 生活被记录后留下的痕迹
- 一个人和自己相处的时间证明
- 日记里的小型档案
- 个人成长过程中留下的章节标记
- 未来回看时会觉得“原来我走了这么远”的证据

而不是：

- 为了集齐而集齐
- 为了数字进度而打卡
- 为了稀有度而制造压力
- 为了游戏化而游戏化

### 2. 视觉元素可能太多

请检查是否存在这些问题：

- 背景大面积使用多色径向渐变
- 主色、分类色、稀有度色、AI 图片颜色同时争夺注意力
- 每张卡片都有圆角、阴影、渐变或装饰
- 顶部统计、入口卡、筛选条、徽章网格层层堆叠
- 首屏还没有看到真正的成就内容，就已经出现很多说明模块
- 画廊、陈列柜、挑战有各自的视觉语言，但没有一个最核心的主语言
- 组件看起来精致，但整体像设计稿展示，而不是一个会长期使用的页面

请减少“我做了很多视觉效果”的感觉。

### 3. AI 生图资产可能不适合作为最终资产

当前 designs/achievement-assets/ 下的图片存在以下风险：

- 图片风格虽然柔和，但有的更像简单插画占位
- 部分图片留白过多，在小徽章中识别度不够
- 主题之间构图不够稳定
- 颜色和稀有度颜色混在一起
- 生成图带有水印或文字
- 图片如果直接作为卡片背景，会和页面文字抢层级
- 图片可能无法在深色模式中保持可读
- 如果每个成就都完全不同，会破坏整体感

AI 生图应该服务于界面，不应该让界面围绕图片堆效果。

## 三、核心产品方向

请把成就页面定义为：

一个记录生活痕迹的私人档案馆，而不是游戏成就大厅。

更具体地说：

- 成就是日记行为留下的证据。
- 每个成就都应该能回答“我为什么获得它”。
- 已解锁成就应该有来源、日期、相关日记或触发事件。
- 进行中的成就应该告诉我“还差什么”，但不要制造焦虑。
- 未解锁成就可以保留神秘感，但不能用灰色废卡片填满页面。
- 传奇成就应该有更强的叙事感，不只是更亮的金色。
- 成就详情应该让用户回到自己的生活，而不是只看一张漂亮徽章。
- 页面应该让用户感到“我被自己的生活记录留下了”，而不是“系统在给我打分”。

视觉关键词：

- 私人档案
- 日记收藏
- 生活证据
- 柔和但不甜腻
- 有一点收藏感
- 安静
- 细腻
- 真实
- 有阶段感
- 可回看
- 不浮夸
- 不像游戏大厅
- 不像数据仪表盘
- 不像营销页面

## 四、工作流程

不要直接写最终代码。严格按以下顺序工作。

### 第一步：输出设计诊断

先用不超过 1000 字回答：

1. v5 最主要的问题是什么。
2. 哪些现有功能应该保留。
3. 哪些视觉元素应该删减或降级。
4. 页面应该让用户产生什么感觉。
5. 准备采用什么单一视觉方向。

不要一次给我五套互相冲突的方案。

### 第二步：提出一个主方向

只提出一个最适合 DiaryApp 的方向，并给它起一个简短名字。

可以参考：

- 私人档案柜
- 生活痕迹馆
- 日记里的小型博物馆
- 安静的成长档案
- 收藏那些走过的日子

名字只是帮助统一设计，不要把页面做成真实博物馆或复古主题。

说明：

- 页面整体气质
- 信息层级
- 卡片形态
- 徽章形态
- 图像使用方式
- 颜色逻辑
- 深色模式逻辑
- 动效逻辑

### 第三步：输出页面结构

明确说明以下内容的顺序和作用。

#### 顶部区域

需要包含：

- 返回
- 页面标题
- 一句很短的副标题或说明
- 是否需要统计数据
- 是否需要设置或筛选入口

不要在顶部放太多统计数字。

#### 成就概览

请决定是否保留：

- 已解锁数量
- 总完成度
- 最近解锁
- 最接近完成的成就
- 当前等级或经验
- 传奇数量

默认优先保留“最近解锁”和“最接近完成”，因为它们比单纯数字更有叙事价值。

#### 主视图切换

重新审视是否需要：

- 画廊
- 陈列柜
- 月度挑战

保留这些功能时，不要让它们看起来像三个完全不同的产品。它们应该共享同一套视觉系统。

#### 筛选

当前 v5 有：

- 稀有度筛选
- 状态筛选
- 分类筛选

不要把三整行筛选胶囊直接堆在页面顶部。

请采用以下方案之一：

- 一个筛选按钮打开底部面板
- 一个主筛选条 + 底部面板选择更多条件
- 一行横向筛选，但控制数量和层级
- 搜索与筛选合并为一个清晰入口

默认推荐：页面只展示一行简洁的主筛选，更多条件进入底部面板。

#### 成就网格或列表

请判断使用：

- 三列小型徽章网格
- 两列较大卡片
- 混合布局
- 最近成就横向展示 + 其余三列网格

默认推荐：

- 保留三列紧凑网格，符合现有页面密度。
- 顶部只突出一张最近解锁或最接近完成的成就。
- 不要把每个成就都做成大卡片。
- 不要让每个成就占据半屏高度。

## 五、成就状态和卡片要求

### 已解锁

显示：

- 徽章或封面
- 成就名称
- 分类
- 稀有度
- 已解锁状态
- 可选的解锁日期
- 如果有来源，显示一个很短的来源提示

不要显示过多文字。

### 进行中

显示：

- 成就名称
- 当前进度
- 目标
- 小型进度条或环形进度
- 一句轻量提示

示例：

- 312 / 365 天
- 还差 53 天
- 已完成 73%

不要显示：

- 失败
- 未完成
- 红色警告
- 过于强烈的倒计时
- 让用户产生被考核感觉的措辞

### 锁定

请选择一种锁定策略：

1. 清晰显示名称和条件。
2. 显示名称，但隐藏具体条件。
3. 隐藏名称，只显示模糊线索。

隐藏成就建议：

- 不要使用一堆完全相同的灰色锁头卡片。
- 保留轻微视觉差异。
- 使用简短线索。
- 允许用户进入详情查看线索。
- 解锁之后显示完整内容。
- 不使用惊吓、黑色恐怖、强烈噪点或故意故弄玄虚。

### 卡片操作

点击卡片进入详情。

详情需要包含：

- 徽章或封面
- 成就名称
- 分类与稀有度
- 风味文案
- 当前状态
- 进度或解锁日期
- 关联日记片段或来源
- 查看对应日记
- 加入或移出心愿单
- 分享
- 关闭或返回

原型中的“模拟解锁”只能作为演示功能，并且必须明确标注为“原型演示”。真实产品不能让用户随便模拟解锁。

## 六、视觉设计系统

### 背景

不要使用三种以上大面积彩色径向渐变。

推荐：

- 主题色只做小范围环境色。
- 页面底色保持中性。
- 卡片表面与背景有足够区分，但不要全部漂浮。
- 可以有轻微纸张感，但不要整页变成奶油色。
- 深色模式使用中性墨色背景，不要让红、橙、紫成为整页底色。

### 颜色

使用两层颜色系统。

中性层用于：

- 页面背景
- 卡片表面
- 正文
- 次要文字
- 分割线
- 锁定状态

语义层用于：

- 分类标识
- 稀有度小标签
- 进度条
- 当前筛选
- 解锁成功
- 轻微强调

分类色和稀有度色不能同时以高饱和度大面积出现。

推荐稀有度颜色：

- 普通：灰绿或浅石色
- 稀有：低饱和蓝色
- 史诗：低饱和紫红或珊瑚色
- 传奇：低饱和琥珀色

要求：

- 不使用高饱和荧光色。
- 不让每一张卡片变成不同颜色。
- 不使用彩虹渐变作为主要按钮。
- 不让紫色渐变统治整个页面。
- 深色模式只提高语义色的明度和对比度，不改变背景色为语义色。

### 卡片

卡片应该是内容容器，不是装饰物。

要求：

- 不要每张卡片都使用不同造型。
- 不要大量倾斜、折角、邮票、票据和悬浮阴影。
- 核心成就卡保持规整。
- 特殊内容最多使用一种轻微装饰。
- 圆角保持克制，避免大圆角胶囊化。
- 不要使用卡片套卡片套卡片。
- 不要把所有内容放进漂浮面板。
- 页面主体应该有平面层次，只有真正需要聚焦的内容才使用卡片。

### 字体

- 中文正文优先使用清晰的无衬线字体。
- 衬线字体只用于成就名称、风味文案或页面主标题。
- 成就名称不能太小。
- 分类和稀有度用小字，但必须可读。
- 不要使用大量英文标签。
- 不要全大写英文装饰。
- 不要使用负字距。
- 正文行高保持舒适。

### 图标

- 使用简洁的线性图标或现有 Material 图标。
- 不要把图标、AI 图片、颜色、星星、锁头全部叠加在一起。
- 一个成就徽章内部只保留一个主要视觉符号。
- 锁定成就使用低对比锁或轮廓，不要巨大锁头覆盖一切。
- 图标按钮必须有清晰的无障碍描述。

## 七、AI 生图要求

当前已有 designs/achievement-assets/ 目录，但不要直接接受现有图片为最终方案。先判断是否需要重做。

统一艺术方向：

quiet editorial illustration, tactile paper texture, restrained gouache and colored pencil, soft natural light, simple symbolic still life, calm personal archive, muted sage, dusty blue, warm apricot, off-white paper, centered composition, high readability at small size

中文解释：

- 安静的编辑插画
- 轻微纸张质感
- 淡彩水粉或彩铅
- 简单的象征性静物
- 柔和自然光
- 私人档案气质
- 低饱和青绿、灰蓝、杏色和纸白
- 主体居中
- 缩小后仍然清楚

禁止：

- 文字
- 水印
- Logo
- “图片由 AI 生成”
- UI 截图
- 徽章边框
- 直接生成完整卡片
- 直接生成“成就”两个字
- 复杂人物
- 游戏角色
- 赛博朋克
- 霓虹光
- 金色爆炸
- 粒子满屏
- 过度梦幻
- stock photo
- 过度写实
- 彼此完全不同的画风
- 过度空白导致缩小后看不清主体

图片技术要求：

- 1:1
- 至少 1024 x 1024
- 主体集中在中央安全区域
- 不带文字
- 不带水印
- 适合圆形、方形或小卡片裁切
- 亮色和深色界面都能使用
- UI 决定分类色和稀有度色，图片本身不要强行带稀有度颜色

分类图建议：

时间：太阳从纸张地平线上升起、日历页的影子、钟表与光线。不要画成普通闹钟图标。

心情：一杯水、不同色层的玻璃、平静水面、细微波纹。不要画成一排表情符号。

天气：窗边的雨痕、云影、湿润的纸面、被风吹动的树叶。不要画成天气 App 图标。

写作：纸张、墨水、羽毛笔、被写过的页角、折叠的手稿。不要画成巨大的单独钢笔图标。

习惯：一株正在生长的植物、重复的刻度、桌面上的小盆栽。不要画成健身打卡界面。

探索：地图折痕、路标、车票、指南针、旅途中留下的纸片。不要画成游戏地图或旅游广告。

收藏：抽屉、夹子、被保存的纸条、照片背面、旧票根。不要画成宝箱或金币。

传奇：夜色中的一盏灯、被翻到最后一页的书、远处的微光。不要画成皇冠、火焰、钻石或夸张金色徽章。

请先生成一张 8 分类风格测试板，再决定是否批量生成。不要一次生成 40 张彼此不一致的图。

## 八、交互设计要求

必须支持：

- 画廊、陈列柜、挑战切换
- 状态筛选
- 分类筛选
- 稀有度筛选
- 点击卡片进入详情
- 返回
- 心愿单
- 详情内查看来源
- 原型演示解锁
- 解锁后状态立即更新
- 适度 Toast 或状态反馈
- 浅色和深色模式
- 主题色切换

动效要克制：

- 点击卡片：轻微缩放，150 至 220ms
- 页面切换：淡入或轻微上移，150 至 300ms
- 解锁：徽章轻微放大、柔光出现，不超过 1.2 秒
- 进度变化：平滑填充
- 不使用大面积粒子
- 不使用持续漂浮
- 不使用页面级旋转
- 不使用闪烁干扰
- 支持减少动态效果

触控要求：

- 触控目标不小于 44dp
- 筛选按钮容易点击
- 卡片点击区域完整
- 收藏、更多操作和返回有明确反馈
- 不把重要操作藏在 hover 状态中

## 九、文案要求

文案要像 DiaryApp，不像游戏运营活动。

推荐语气：

- 这段日子被你留下来了。
- 你已经连续记录 312 天。
- 这枚成就来自一篇雨天日记。
- 还差 53 天，不急，慢慢来。
- 有些成就不是完成任务，而是没有错过自己。

避免：

- 快去完成！
- 距离胜利只差一步！
- 燃起来！
- 你必须坚持！
- 击败目标！
- 领取奖励！
