# DiaryApp v2.70.5-experimental

发布日期：2026-06-27

## 本次重点

- 补齐了 `2.69.0` 之后多条未真正闭环的主路径功能，避免“页面存在但功能不通”。
- 重点治理了提醒设置、首页搜索、周报入口、写作目标、报告分享、标签层级、地图热力图等断链问题。
- 对高风险问题做了止血：数据库 destructive migration、敏感配置存储、备份导入链路、图片恢复链路。
- 修复了一批你明确指出的体验和回归 bug，尤其是备份恢复、成就误创建日记、天气页顶部空白、通知残留、搜索框视觉异常。

## 修复与优化

### 稳定性与安全

- 统一提醒设置、通知设置和提醒调度链路，设置修改后会真实生效。
- 移除了 release 路径上的破坏性数据库回退，改为显式迁移失败处理。
- 新增安全配置存储，迁移 AI 配置与 PIN 相关敏感数据。
- 保留 release 混淆与资源压缩，继续控制包体和暴露面。

### 备份与恢复

- 修复新版无法稳定读取旧备份文件的问题，兼容更多可读路径。
- 恢复/导入时会重建 `diary_images` 索引，降低“图片丢失但文本还在”的概率。
- 完整备份会额外扫描磁盘媒体文件，不再只依赖旧索引。
- 导入前增加备份预检，直接提示：
  - 是否为完整备份包
  - 日记/标签/待办/时间胶囊数量
  - 媒体文件数量
  - 引用媒体数量
  - 缺失媒体数量
- 对旧式纯 JSON 备份明确提示“无法完整恢复图片”。

### 首页与搜索

- 首页搜索补齐建议面板、历史记录、筛选闭环。
- 新增标签、地点、字数等筛选能力。
- 支持“仅筛选无关键词”的结果模式。
- 搜索框表面样式已调整为贴合当前主题，不再出现不自然透明感。

### 报告与目标

- 周报正式接入主导航路径，不再是半成品孤岛页面。
- 统计页补齐周报/月报/年报主入口。
- 写作目标在首页和统计页共享同一套真实进度逻辑。
- 月报、年报、周报补齐图片优先分享链路，文本作为兜底。

### 标签与地图

- 标签支持正确的父子层级治理。
- 修复标签树展开、移除父标签、循环选择保护等问题。
- 父标签筛选会自动覆盖子标签日记。
- 地图补齐真实热力图展示，不再只是模式开关。
- 修复部分地点字符串解析错误导致的城市统计偏差。

### 体验修复

- 修复成就达成时误创建日记的问题。
- 修复成就详情图片模糊且不符合主题的问题。
- 清理通知内遗留的宠物/小岛相关残留内容。
- 修复天气详情页顶部空白和标题不贴顶的问题。

## 验收重点建议

- 导入旧版备份、完整备份包，确认文本与图片恢复表现。
- 修改提醒时间与开关，确认通知是否按设置真实变化。
- 首页搜索分别测试：
  - 关键词搜索
  - 仅筛选
  - 父标签筛选
  - 地点筛选
- 从统计页进入周报，并测试周报分享。
- 地图页切换热力图模式，确认覆盖层可见。
