# 首页日记多选管理设计

## 目标

在首页按日期查看当天日记时，支持长按进入多选模式，对多篇日记进行批量收藏和批量删除，减少逐篇进入详情页操作的成本。

## 设计范围

- 仅作用于首页当前选中日期下展示的日记列表
- 长按任意日记卡片进入多选模式
- 进入多选后，首个长按的日记自动选中
- 多选模式下，点击卡片切换选中状态
- 顶部日期区域切换为多选操作栏，显示已选择数量
- 提供 `收藏`、`删除`、`取消` 三个操作
- 批量收藏为统一设为已收藏，不做切换
- 批量删除为统一删除，沿用现有回收站逻辑
- 删除前弹出确认框，避免误删

## 交互说明

### 进入多选

用户在首页选中某一天后，长按当天任意一篇日记卡片，页面进入多选模式，并自动选中该日记。

### 多选状态

- 顶部标题从日期信息切换为 `已选择 X 篇`
- 点击未选中的卡片会加入选中
- 点击已选中的卡片会取消选中
- 当选中数变为 0 时，保留多选模式，用户可继续点选或点击取消退出

### 批量收藏

- 点击 `收藏` 后，将当前选中的全部日记统一标记为已收藏
- 已收藏的日记再次执行该操作时保持不变

### 批量删除

- 点击 `删除` 后先展示确认弹窗
- 用户确认后，将所有选中日记移入回收站
- 删除完成后退出多选模式并清空选中状态

### 退出多选

- 点击 `取消` 退出多选模式
- 切换日期时自动退出多选模式并清空当前选择

## 实现边界

- 不新增独立管理页面
- 不加入批量取消收藏
- 不加入跨日期多选
- 不修改首页原有整体布局，仅在顶部局部替换操作区

## 数据与实现思路

- 首页 UI 使用现有 `multiSelectMode` 与 `selectedIds` 状态完成交互
- `HomeViewModel` 增加批量收藏与批量删除方法
- 批量删除复用现有单条删除逻辑，确保仍进入回收站
- 如果 DAO 没有现成批量接口，可先在 ViewModel 中循环调用现有方法，保持实现简单稳定

## 验收标准

1. 长按当天任意日记可进入多选模式
2. 多选模式下可连续选择多篇日记
3. 点击收藏后，所有选中日记变为已收藏
4. 点击删除后，所有选中日记进入回收站且首页列表同步刷新
5. 点击取消或切换日期后，多选状态被清空
6. 首页整体视觉保持简洁，不引入复杂新布局
