## 一、设计背景

### 1.1 现状分析

当前存在两套平行系统：

| 系统 | 数量 | 特点 | 问题 |
|------|------|------|------|
| Achievement | 16个 | 基础进度追踪，无分类/稀有度 | 与称号系统功能重叠，UI简单 |
| Title | 35+个 | 7分类/3稀有度/风味文字/装备/动画 | 更完整，但缺乏进度可视化 |

### 1.2 合并目标

将两套系统合并为一个**统一的成就系统**，保留Title系统的完整设计，吸收Achievement的进度追踪优势，实现：

- 统一的数据模型和UI入口
- 更丰富的成就分类体系
- 渐进式解锁体验
- 与宠物/小岛系统的深度联动

## 三、视觉设计方案

### 3.1 徽章设计风格

#### 设计原则
- **简洁现代**：几何形状，无过多装饰
- **层次分明**：稀有度通过视觉元素清晰区分
- **情感共鸣**：图标传达成就的意义
- **统一协调**：与App整体设计语言一致

#### 图标设计规范

**基础形状**:
- 普通：圆形 (48dp)
- 稀有：圆角矩形 (48dp, 12dp圆角)
- 史诗：八边形 (52dp)
- 传说：徽章形 (56dp, 含尖角)

**图标元素**:
```
普通:  [纯色背景] + [单色图标]
稀有:  [渐变背景] + [白色图标] + [1px边框]
史诗:  [多层渐变] + [白色图标] + [2px渐变边框] + [内发光]
传说:  [金属渐变] + [金色图标] + [3px金边] + [光效]
```

### 3.3 动画效果设计

#### 解锁动画序列

**阶段 1: 闪光 (0-200ms)**
- 全屏白色闪光，alpha从0.8到0
- 营造"突破"感

**阶段 2: 图标入场 (200-600ms)**
- 图标从scale 0弹出到1.15，再回落到1.0
- 传说级：额外一次0.95-1.05的微弹

**阶段 3: 文字揭示 (400-900ms)**
- "成就解锁!" 逐字打字机效果
- 每字间隔50ms

**阶段 4: 成就名称 (600-1000ms)**
- 名称从下方滑入，alpha渐显
- 字体：24sp, Bold

**阶段 5: 粒子效果 (持续)**
- 普通：12个圆点，单色
- 稀有：24个，圆点+星形
- 史诗：36个，圆点+星形+碎片
- 传说：48个，彩虹色，三形状混合

**阶段 6: 脉冲光环 (持续)**
- 两层同心圆，交替脉冲
- 周期：1.5s

#### 粒子设计

```kotlin
enum class ParticleType { DOT, STAR, FRAGMENT }

data class Particle(
    val offsetX: Float,      // 方向X (-1..1)
    val offsetY: Float,      // 方向Y (-1..1)
    val size: Float,         // 大小 2-8
    val color: Color,        // 颜色
    val speed: Float,        // 速度 0.5-2.5
    val rotationSpeed: Float,
    val type: ParticleType
)
```

#### 动画参数对比

| 稀有度 | 粒子数 | 动画时长 | 光效 | 特殊效果 |
|--------|--------|----------|------|----------|
| 普通 | 12 | 1.5s | 无 | 简单scale+fade |
| 稀有 | 24 | 2.5s | 微弱外发光 | 星形粒子 |
| 史诗 | 36 | 3.5s | 脉冲光环 | 碎片粒子 |
| 传说 | 48 | 5s | 旋转光效 | 彩虹粒子+三形状 |

## 十、总结

本设计方案将称号系统和成就系统合并为一个统一的成就系统，核心特点：

1. **统一架构**: 8大分类 + 4级稀有度 + 渐进式进度
2. **精美视觉**: 几何徽章 + 渐变色彩 + 粒子动画
3. **情感共鸣**: 每个成就都有独特的风味文字
4. **深度联动**: 与宠物、小岛系统紧密配合
5. **分享传播**: 精美的分享卡片设计

预期效果：让用户在记录日记的过程中，获得持续的成就感和情感连接，增强产品的粘性和用户满意度。
