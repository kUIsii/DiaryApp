- **分层架构**：采用 UI (`ui/`)、数据 (`data/`)、业务逻辑 (`ai/`, `reminder/`, `health/`) 分离的设计。`DiaryApplication` 作为全局入口，通过 `AppContainer` 实现简易依赖注入。
- **数据持久化**：使用 Room 数据库 (`DiaryDatabase.kt`) 管理日记、待办、成就等实体，包含复杂的版本迁移逻辑 (`MIGRATION_1_32`) 和启动时数据预热 (`warmUpCoreData`)。
- **导航与界面**：基于 Jetpack Navigation Compose (`DiaryNavHost.kt`) 实现单 Activity 多屏幕架构，底部导航栏包含首页、时间轴、工具、待办和个人中心五大模块。
- **异步与后台**：利用 Kotlin Coroutines 处理并发，WorkManager 调度自动备份、天气更新和垃圾清理等周期性任务。
- **外部集成**：集成高德地图 SDK 实现日记地图，Health Connect API 同步健康数据，以及 WebView 嵌入富文本编辑器。
