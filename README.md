# DiaryApp — 你的私人智能日记

一款功能丰富、隐私优先的 Android 日记应用。基于 **Jetpack Compose** + **Room** 构建，60+ 功能，259 个 Kotlin 源文件，~62,000 行代码。

## ✨ 功能亮点

### 📝 写作体验
- **富文本编辑器** — 基于 Quill Delta 的所见即所得编辑，支持标题/粗体/列表/图片/引用
- **语音录入** — 录音 + 自动转写文字
- **快速签到** — 心情选择 + 文字 + 拍照，一键记录
- **写作模板** — 10+ 预设模板（每日/感恩/旅行/创意等）
- **AI 写作助手** — AI 生成灵感/提示/续写

### 🧠 AI 深度能力
- **AI 智能助手** — 多轮对话，支持 Deepseek/ModelScope/自定义 API
- **AI 传记** — 自动生成个人生命故事
- **写作教练** — 词频/句长/情绪分布分析 + 个性化建议
- **日记摘要** — 每篇日记的 AI 摘要
- **语义搜索** — TF-IDF + 中文二元分词全文检索
- **情绪弧线** — 日记情绪变化可视化
- **洞察生成** — AI 发现写作模式与规律

### 🎨 可视化与数据
- **心情地图** — 高德地图集成，心情着色标记 + 路线模式
- **年度报告** — Spotify Wrapped 风格的年度回顾（1317 行动画卡片）
- **月度报告 / 季度回顾** — 统计图表
- **情绪雷达 / 情绪预报** — 多维情绪可视化
- **日历热力图** — GitHub 风格的写作连续打卡图
- **词云** — 关键词频率可视化
- **个人年鉴** — 年度数据汇总 + **PDF 导出**

### 🔐 隐私与安全
- **生物识别锁** — 指纹 / 面部识别
- **PIN 码锁** — 4 位数字备用解锁
- **防截屏保护** — 阻止其他应用截屏/录屏
- **全部数据本地存储** — 无需注册，无需联网

### 🎯 成长与反思
- **目标追踪** — 层级子目标 + 进度条
- **小确幸记录** — 每日感恩小事
- **月度挑战** — 写作目标挑战
- **连续保护罩** — 写作 streak 保护
- **决策追踪** — 重大决策回顾与分析
- **价值观提取** — 从日记中识别个人价值观
- **成就系统** — 40+ 成就，8 大类别
- **称号系统** — 游戏化成长体系
- **时间胶囊** — 给未来的自己写信
- **倒数日** — 重要日期倒计时

### 🔗 关联与记忆
- **条目关联图谱** — 标签关联的可视化图
- **记忆锚点** — 主题相关的日记分组
- **地点触发回忆** — 地理围栏回提醒
- **旅行日志** — 按旅行组织日记
- **那年今日** — 往年间日期的日记
- **随机回顾** — 随机重温旧日记
- **沉浸阅读** — 翻页 + 暖光滤镜

### 🛠 系统功能
- **标签系统** — 多标签管理
- **收藏** — 标记重要日记
- **回收站** — 30 天自动清理
- **本地备份/恢复** — JSON 导出导入
- **桌面小组件** — Todo + 倒数日
- **专注模式** — 番茄钟 + 环境音
- **天气集成** — 天气自动获取
- **健康数据** — Health Connect 集成（步数/睡眠/心率）
- **手势快捷操作** — 5 种手势映射
- **锁屏快写** — 不解锁快速记录
- **自适应界面** — 深色/自动夜间/精简模式
- **安静陪伴 / 环境主题** — ambient 体验
- **更新通知** — 内建更新检查 + 安装

## 🏗 技术架构

| 层 | 技术 |
|---|---|
| **语言** | Kotlin 100% |
| **UI** | Jetpack Compose + Material 3 |
| **数据库** | Room（v35，37 实体，34 步迁移） |
| **导航** | Navigation Compose（45+ 路由，5 底部 Tab） |
| **架构** | MVVM（AndroidViewModel + StateFlow） |
| **依赖注入** | 手动 DI（AppContainer） |
| **后台任务** | WorkManager |
| **图片加载** | Coil 2.5.0 |
| **地图** | 高德地图 3D SDK 10.0.600 |
| **AI** | 多 Provider（Deepseek / ModelScope / 自定义） |
| **生物识别** | AndroidX Biometric 1.1.0 |
| **健康** | Health Connect API |
| **富文本** | Quill.js（WebView） |
| **构建** | Gradle Kotlin DSL + R8 混淆 |
