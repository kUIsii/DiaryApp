## DiaryApp v2.61.18-experimental

This experimental build continues refining the diary editor UI:

- Metadata chips now show the selected content directly, with mood and weather icons when selected.
- Removed the focus/full editor mode switch so the toolbar only has visible and hidden states.
- Restored the default rich editor toolbar behavior and removed the indent shortcut.
- Reduced extra WebView bottom padding so the writing area uses the available page height.
- Improved ruled-paper coverage so the editor fills the visible writing surface more consistently.
- Adjusted cursor auto-scroll so writing near the bottom scrolls naturally instead of wasting space.
